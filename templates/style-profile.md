## 二、风格指纹(AI 从样本提取,写作时必须遵守)

### 1. 句长分布
- 平均句长:约 __ 字(短句为主 <15 / 中句 15-25 / 长句 >25)
- 长短句比例:短:中:长 ≈ __ : __ : __
- 最长连续长句数:≤ __ 句

### 2. 段落习惯
- 每段平均 __ 行(1-2 行碎段 / 3-5 行常段 / 长段)
- 正文段落与对话段落的比例

### 3. 标点习惯
- 省略号使用:频繁 / 偶尔 / 几乎不用
- 破折号、问号、感叹号的使用倾向
- 对话前是否带"说道/问"等引导词(带 / 不带 / 混合)

### 4. 词汇指纹
- 高频词汇:
- 角色口头禅(如有):__ 个,各属于谁
- 粗口/脏话使用度:无 / 轻度 / 频繁
- 方言或特色词汇:

### 5. 意象偏好
- 常取意象(烟火气 / 江湖气 / 科技感 / 乡土气……):
- 比喻的使用频率:几乎不用 / 偶尔(每章≤2) / 偏好明喻
- 比喻的取象来源(如"杀猪刀""算盘""符纸"):

### 6. 对话风格
- 平均每轮对话字数:短(<10字) / 中等 / 长(陈述式)
- 对话节奏:快问快答 / 一来一往拉锯 / 独白式
- 称呼习惯(哥/叔/姓+职业/全名):
- 对话胜负感:明显 / 平缓

### 7. 情绪表达方式
- 直给 / 隐忍(行为暗示) / 反讽 / 幽默消解
- 心理活动:直接引语式 / 叙述式 / 极少心理描写

### 8. 开篇与章尾偏好
- 章首:环境引入 / 对话切入 / 事件爆发 / 内心独白
- 章尾:悬念钩 / 冲突钩 / 异常钩 / 强情绪钩 / 对话钩 / 动作钩

## 四、临摹验证(启用前必做)

1. AI 按本卡写一段 **150-200 字**与作品无关的场景临摹。
2. 用户对照原文判断"像不像";不像则修改指纹,再临摹一次。
3. 用户确认通过后,该特征卡才可被 `write` 命令加载。

**临摹样本**:

```
（AI 临摹 + 用户确认结果）
```

## 五、风格切换(多风格写作时)

- 全书默认一个主风格卡,存为 `风格/主风格.md`。
- 特殊情况(梦境/番外/反派视角章节)可临时切换,用完后必须切回。
- 每写 10 章回读一次本卡,检查是否漂移回通用文风,漂移则回炉。
